방법 1 (권장)
템플릿에서
태그는 layout에 추가해둬서 그 하위 template에서는 사용할 필요가 없음

((html 태그에 xmlns:sec="http://www.thymeleaf.org/extras/spring-security" 항목 넣기

예시 : <html xmlns:layout="http://www.ultraq.net.nz/thymeleaf/layout"
	xmlns:sec="http://www.thymeleaf.org/extras/spring-security">)) 필요없음

sec:authentication="principal.필드"로 꺼내쓰기

예시 : <span><strong sec:authentication="principal.name"></strong>님</span>


principal이 userVO라서 principal.name, principal.tel, principal.adminCd 등등 꺼내쓰면 됨

주의! : userVO를 다음과 같이 변경함
private String adminCd;  // 공통코드 그대로 출력
private String adminNm; // 이름으로 변환 함수 사용함
함수를 통해서 이름을 가져오는 방식을 쓸 때 VO와 .xml 파일을 이렇게 2개 필드로 나눠서 가져오면 편리해 보여서 수정하였기 때문에 사용시 재확인바람 (05.18 merge 이후부터)

((userVO를 db에서 꺼낼 때 .xml파일에서 진환씨가 만들어준 함수를 사용해서 서브코드 이름으로 되어있음
'01ACTIVE'가 아니고 '활성' 으로 userVO 필드에 저장되어있음
즉 principal.adminCd 를 사용하면 '01ROLE' 이 아니라 '시스템관리자' 형식으로 되어있어서 꺼내서 쓸 때 확인필요
공통코드를 프론트에 표시할 때는 그냥 사용하면 바로 글자로 나와서 편리하지만 db에 넣을때는 다시 코드화 해서 넣어야함)) 필요없음
