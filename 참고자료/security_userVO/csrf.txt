를 레이아웃에 추가함

Security에서 보안 설정하는데 AJAX 통신할때도 영향을 줌

예시
// csrf 선언 필요
const csrfToken = csrfMeta.content;
const csrfHeader = csrfHeaderMeta.content;

const response = await fetch('/email/send', {
				                    method: 'POST',
				                    headers: {
				                        'Content-Type': 'application/json',
				                        [csrfHeader]: csrfToken // 헤더에 필수
				                    },
				                    body: JSON.stringify({
				                        bizNo: bizNo.value,
				                        login: login.value,
				                        email: email.value
				                    })
				                });

이걸 안적기 위해서 공통 js를 만들어뒀음
경로 위치 static/js/common/csrf.js

이걸 레이아웃에 적용을 했기 때문에 일종의 전역함수로 적용이 되고
fetch 함수 대신 csrfFetch 함수를 사용하면 csrf 선언이랑 헤더에 정보를 적을 필요가 없음.

예시
const response = await csrfFetch('/email/send', {
				                    method: 'POST',
				                    headers: {
				                        'Content-Type': 'application/json',
				                    },
				                    body: JSON.stringify({
				                        bizNo: bizNo.value,
				                        login: login.value,
				                        email: email.value
				                    })
				                });
